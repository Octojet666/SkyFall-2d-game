# assets/

This folder is empty on purpose. The artwork the game was built against is
third-party and cannot be redistributed, so bring your own.

The expected file list, pixel sizes and grid layouts are in
[../ASSETS.md](../ASSETS.md). Keep the same paths and filenames and the game
picks them up with no code changes.

Until you add something here the game still runs — anything that has no image
falls back to a plain coloured shape.
